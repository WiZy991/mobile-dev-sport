FitnessClub Agent - install guide
=================================

OPTION A - Setup.cmd (recommended)
  1. Put Setup.cmd and FitnessClubAgent-Setup-*.zip in the same folder
  2. Double-click Setup.cmd
  3. No Python needed (EXE is already inside the ZIP)

OPTION B - ZIP package
  1. Extract the ZIP
  2. Double-click install.bat
  3. Agent installs to %LOCALAPPDATA%\FitnessClubAgent

After install
  1. Open "FitnessClub Agent"
  2. CRM tab: base URL (no /admin), gateway_token, Save all
  3. Equipment: set entry/exit reader numbers, Apply, Save, restart agent

Config file
  %LOCALAPPDATA%\FitnessClubAgent\config\agent_config.json

Download prebuilt package
  GitHub Actions artifact "FitnessClubAgent-Setup" (workflow Build FitnessClub Agent)
