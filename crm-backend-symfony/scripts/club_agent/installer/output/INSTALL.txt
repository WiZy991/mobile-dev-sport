FitnessClub Agent 1.0.2 - install
=================================

OPTION A - one click (recommended)
  1. Put Setup.cmd and FitnessClubAgent-Setup-1.0.2.zip in the same folder
  2. Install Python 3 from python.org (check "Add python.exe to PATH") — once
  3. Double-click Setup.cmd
     It will build FitnessClubAgent.exe, then install to %LOCALAPPDATA%\FitnessClubAgent

OPTION B - ZIP only
  1. Extract FitnessClubAgent-Setup-1.0.2.zip
  2. Double-click install.bat
     (if exe is missing, install.bat builds it first — Python required)

After install
  1. Open FitnessClub Agent
  2. CRM: URL + gateway_token → Save
  3. Equipment: set entry/exit reader numbers → Apply → Save → restart agent

Config
  %LOCALAPPDATA%\FitnessClubAgent\config\agent_config.json

Changelog 1.0.2
