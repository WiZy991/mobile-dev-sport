## Что сделано в этой сессии (профиль 16–18, 14, 25, 26)

1. **Gate `needs_profile`** после оплаты аренды: без телефона и специализации из справочника рабочие API закрыты.
2. **Справочник специализаций** (15 позиций, max 5) — чипы в `TrainerProfileScreen`, нормализация на backend.
3. **Регистрация**: обязательные галочки оферты и согласия на ПД.
4. **Профиль**: блок аренды, ссылки на документы, брендинг шапки «Сотрудник».

## Что нельзя закрыть без бизнеса/юриста

Пункты **1–5, 28, 50, 52** и полностью **18** (расширенный пакет полей по договорам). Без скрипта регистрации и текста оферты любое «красивое» UI будет переделываться.
